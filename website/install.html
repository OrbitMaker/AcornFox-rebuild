🚀 快速安装

在 Linux 服务器上一键安装 AcornFox，自动配置所有依赖。

服务器端安装

curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install.sh | sudo bash

客户端 CLI 安装

在本地安装 AcornFox CLI 工具：

curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install-cli.sh | bash

🔧 系统要求

  • 操作系统

    Ubuntu 24.04 / 22.04 / 20.04、Debian 12 / 11（amd64 或 arm64）

  • 硬件配置

    最低 2 核 2GB RAM，推荐 2 核 4GB RAM

    公网 IP（可选），开放 80/443 端口

📖 手动安装

如果自动安装遇到问题，可以手动执行：

1. 下载安装脚本

curl -fsSLO https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install.sh
chmod +x install.sh

2. 执行安装

sudo ./install.sh

3. 国内加速（可选）

如果在中国大陆，脚本会自动检测并使用镜像源。也可以手动指定：

sudo ./install.sh --china
