安装指南

推荐把下面这句话发给你的 AI 工作台：先装 Skill，再由 Skill 判断你的电脑和服务器在国内还是海外，选对下载源，装好命令行工具与服务端，然后部署。

请安装 AcornFox Skill：下载 https://acornfox.com/skill/SKILL.md ，保存为你 skills 目录下的 acornfox/SKILL.md（Claude Code 是 ~/.claude/skills，Codex 是 ~/.codex/skills），然后按这个 Skill 把当前项目部署到我的服务器。

下面是手动安装的步骤，与 Skill 自动执行的步骤相同。

服务器系统Ubuntu 24.04 / 22.04 / 20.04，Debian 12 / 11
架构与配置amd64 或 arm64，建议 2 核 2 GB 以上
你的电脑macOS、Linux 或 Windows（Git Bash），能 SSH 登录服务器

  1. 在服务器上安装

    以 root 或 sudo 执行。中国大陆服务器自动使用 Gitee 镜像与国内软件源；下载的程序按 SHA256 校验。

    中国大陆服务器

    curl -fsSL https://gitee.com/VIP13390/AcornFox-rebuild/raw/main/scripts/install/install.sh | sudo bash

    其他地区

    curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install.sh | sudo bash

    装好后会显示管理员令牌，也保存在 /root/.acornfox-token。

    常用选项

    选项说明
    --version v0.3.1安装指定版本，默认最新
    --public-host HOST访问地址里显示的主机，默认从云厂商元数据取公网 IP
    --registry-mirror URLDocker Hub 加速地址；阿里云服务器建议用控制台“容器镜像服务 → 镜像加速器”里的专属地址
    --china / --global强制使用国内或国际下载源
    --skip-docker / --skip-caddy跳过已经装好的组件
    --public-console 域名开通公网访问控制台（默认不开通）。先把域名解析到本服务器并放行 80、443，安装时自动验证域名、申请 HTTPS 证书并生成登录密码；以后也可以用 acornfox public-console enable 域名 开通

    通过管道传参：curl … | sudo bash -s -- --china

  2. 放行安全组端口

    云服务器默认只开放 22 端口，请在云厂商控制台的安全组里添加入方向规则：

    端口用途
    TCP 18810–18899应用访问端口：http://服务器IP:端口
    TCP 80、443绑定域名并自动 HTTPS 时需要

    中国大陆服务器绑定域名，域名须已完成 ICP 备案，否则无法通过 80/443 访问；未备案时仍可用 IP:端口 访问。

  3. 在你的电脑上安装命令行工具与 Skill

    中国大陆

    curl -fsSL https://gitee.com/VIP13390/AcornFox-rebuild/raw/main/scripts/install/install-cli.sh | bash

    其他地区

    curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install-cli.sh | bash

    再为 AI 工作台装上 Skill（自动识别 Claude Code、Codex；其他工具用 --dir 指定目录）：

    acornfox skill install

  4. 连接服务器

    命令行工具经 SSH 连接，不需要开放额外端口。第一次连接前，先在终端里 ssh 登录一次，确认服务器指纹。

    acornfox target add my-server --ssh root@服务器IP

    不用 root 时，先在服务器上执行一次 sudo usermod -aG acornfox-users 你的用户 并重新登录。

  5. 部署

    在 AI 工作台里说“把这个项目部署到我的服务器”，或在项目目录（含 Dockerfile）手动执行：

    acornfox deploy

    也可以部署公开 Git 仓库 acornfox deploy --git https://github.com/user/repo，或现成镜像 acornfox deploy --image nginx:1.27-alpine --port 80。失败时会输出停在哪一步、原因、建议和日志片段；acornfox diagnose 可以再看一次最近一次部署的诊断，acornfox open 打开网页控制台。

  6. 升级

    自动备份程序与数据库后升级，失败自动回退；运行中的应用不中断。

    中国大陆服务器

    curl -fsSL https://gitee.com/VIP13390/AcornFox-rebuild/raw/main/scripts/install/upgrade.sh | sudo bash

    其他地区

    curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/upgrade.sh | sudo bash
