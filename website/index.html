核心特性

🚀

一键部署

支持本地目录、Git 仓库或 Docker 镜像。一条命令完成部署，自动构建和运行。

🤖

AI 集成

集成主流 AI 工作台（Claude Code、Cursor、Windsurf），通过自然语言完成部署。

🔍

智能诊断

部署失败时返回结构化诊断信息，AI 自动分析并修复问题。

🗄️

附加服务

一键添加 PostgreSQL、MySQL 或 Redis，自动配置连接和数据持久化。

📊

实时监控

查看应用日志和资源使用情况，支持实时跟踪和历史查询。

🌐

自动 HTTPS

已备案域名自动申请 Let's Encrypt 证书，零配置启用 HTTPS。

快速演示

# 1. 安装服务器端（Ubuntu/Debian）
curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install.sh | sudo bash
# 中国大陆服务器：
curl -fsSL https://gitee.com/VIP13390/AcornFox-rebuild/raw/main/scripts/install/install.sh | sudo bash

# 2. 安装客户端 CLI（Windows/macOS/Linux）
curl -fsSL https://github.com/OrbitMaker/AcornFox-rebuild/releases/latest/download/install-cli.sh | bash

# 3. 配置服务器连接
acornfox target add my-server --ssh user@your-server-ip

# 4. 部署你的应用
cd your-project && acornfox deploy

# 5. 查看状态
acornfox status
应用: my-app
状态: live ✓
访问地址: http://your-server:8080
