# 网页控制台：流畅度与设计评审（2026-10-09）

[cc] 在全新国内云主机上按 README 国内命令安装 v0.2.2，部署三个应用（Dockerfile 项目 + PostgreSQL、nginx 镜像、启动即退出的失败应用），经 `acornfox open` 登录控制台，用 Puppeteer 驱动 Chrome 测量并截图（桌面 1440×900、手机 390×844、深浅两种主题）。

## 流畅度：数据

| 项 | 结果 |
| --- | --- |
| 登录跳转 | 约 1.1 秒；会话 Cookie 为 HttpOnly、SameSite=Strict、会话级 |
| 首屏 | 首次绘制 0.16 秒，应用磁贴 0.4 秒出现；5 个资源共 65 KB |
| 打开应用窗口 | 23～79 ms |
| 停止 / 启动 | 点击后约 1.8 秒显示新状态 |
| 空闲开销 | 每 3 秒轮询 `/v1/apps`、`/v1/host`（0.67 次/秒）；主线程约 2.7 ms/秒 |
| 报错 | 桌面与手机均无控制台错误 |

性能本身没有问题。主要问题来自「每次轮询把桌面、工具栏和窗口整体删除重建」（`render()`）。

## 问题清单

### P0 影响使用

1. **选中的文字每 3 秒被清空**：轮询重建 DOM，桌面与日志中的选区在 3.6 秒内全部丢失（日志框每次换成新节点）。用户无法从日志或诊断中复制内容。应只更新变化的节点，或至少不重建日志与诊断区域。
2. **手机上工具栏错乱**：底部 Dock 的按钮文字逐字竖排（「部/署」「服/务/器」），并与窗口重叠。
3. **确认框默认聚焦危险按钮**：停止确认框打开后焦点在「停止」上，回车即停止应用。默认焦点应为「取消」。
4. **「让 AI 部署」窗口出现内部术语**：「安装 AI 工作台技能（N6 提供）」。应改为与官网一致的 Skill 安装提示，并提供复制按钮。

### P1 容易误解

5. **磁贴颜色像状态**：颜色按应用名哈希，健康的应用可能是红色、失败的应用是橙色。改用中性色或品牌色，状态只由角标表示。
6. **失败应用仍显示可点击网址**，以及不适用的操作（未运行时的「停止」、无版本时的「回退到上一版」）。
7. **诊断卡把关键日志折叠**：CLI 直接显示出错行，控制台默认只显示笼统的「容器启动后退出或反复重启」。应默认展开日志片段的最后几行。
8. **网络流量显示 0.0 MB**：KB 级流量被取整为 0，应按大小自动换单位。
9. **「当前版本 · 镜像」**：从目录部署的应用在添加附加服务触发重新部署后显示为「镜像」来源，用户看不懂。
10. **左上角服务器名称为空**，多台服务器时无法分辨当前连接的是哪台。
11. **切换标签页时窗口高度与位置跳动**：窗口按内容高度垂直居中。建议固定窗口高度或顶部对齐。
12. **打开窗口时关闭按钮带粗绿色焦点框**，像被选中。焦点样式应只在键盘操作时显示（`:focus-visible`）。

### P2 体验完善

13. 概览缺少「重启」「重新部署」，CLI 都支持。
14. 部署记录只有版本、状态、时间，缺来源、耗时、失败原因，也不能回退到指定版本。
15. 日志区域无背景和边框，最后一行被截断，看不出可滚动；「跟随新日志」默认关闭。
16. 设置页只读，但没有说明修改方式（CLI 或 AI）。
17. 「部署新应用」窗口内容单薄，命令没有复制按钮。
18. 服务器窗口缺少服务器名称、AcornFox 版本；「相邻轮询之间的平均值」等说明过于技术化。
19. 状态在标题栏和「状态」行重复显示；失败应用「资源：未运行」与「资源指标暂不可用」重复。
20. 手机上标签栏折成两行，网址与「复制」按钮分两行。
21. 品牌与官网不一致：控制台为绿色「A」标志、默认浅色；官网为橡果标志、深色科技风。
22. 重新部署后，日志只显示新容器的内容，之前的日志不可见，界面上没有提示。

无限循环的动画（状态点闪烁、加载转圈）随节点重建每 3 秒从头开始，与第 1 条同源。
