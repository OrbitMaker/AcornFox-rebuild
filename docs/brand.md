# 品牌与界面规范：一拨即开

日期：2026-10-10 [cc]。状态：已采用（负责人确认）。控制台与官网以本文为准。

产品名仍为 AcornFox；品牌名与域名不对齐的问题不在当前考虑范围内。

## 概念

- 口号：**一拨即开** —— 多家算力，一个开关。（英文：One switch. Every cloud.）
- 标志：拨到“开”的开关。左侧三个由小到大的圆点 = 多家厂商、多个区域的算力逐步汇入资源池；右侧开关头 = 用户唯一要做的动作：打开即用。

## 标志

几何（viewBox `0 0 120 60`）：

- 轨道：2:1 胶囊形，`M30 0 H90 A30 30 0 0 1 90 60 H30 A30 30 0 0 1 30 0 Z`
- 开关头：圆心 (90,30)，r=22
- 圆点：直径 7 : 10 : 13，圆心 x = 19.5 / 35.3 / 54.2
- 圆点与开关头为镂空（evenodd）；双色版开关头填白
- 安全区：四周不小于开关头半径
- 最小尺寸：完整版宽度不小于 48px；16–47px 用简化版（去掉圆点）；网站图标单独按像素网格绘制

标志组合（lockup）的文字为 **AcornFox**（2026-10-11 负责人确定 [cc]）：IBM Plex Sans Bold，转成路径，字距按字体自带的 kern。
- 横版 404×60：文字墨迹从 x=147（与图形间距 27）到 402.6，大写高约 40.7（字号 58.3），在 y=30 上下居中。
- 竖版：图形放大 1.1 倍居中，下方间距 24；文字宽度与图形区一致，大写高约 32.5。
- 变体：横版（墨色字）、横版深底用（白字）、竖版，以及分享图 `lockup-horizontal-1200.png`（1200×178，透明底）。

文件：`website/assets/brand/`（SVG 文字已转曲）。控制台使用内联 SVG。

## 色彩

| 名称 | 浅色 / 深色 | 用途 |
|---|---|---|
| 墨 ink | `#13161C` / `#F4F6F7` | 文字与结构；主按钮底色 |
| 运行青 brand | `#14A38B` | 标志、开关开启态、运行中状态点；只作填充，不作小字 |
| 深青 brand-text | `#0C7565` / `#5FD3BE` | 青色文字、链接 |
| 浅青 brand-soft | `#E3F5F1` / `#0F2E29` | 运行中标签底、选中行 |
| 纸 surface-muted | `#F4F6F7` / `#1C2028` | 页面浅底 |
| 面 surface | `#FFFFFF` / `#13161C` | 卡片 |
| 雾 line | `#DDE3E6` / `#2E343D` | 分隔线、卡片描边 |
| 石 ink-muted | `#5A6470` / `#A9B3BC` | 次要文字 |
| 开关关闭轨道 track-off | `#8A949E` / `#6B7580` | 开关关闭态 |

- 运行青上的文字用墨色，不用白色。
- 用量：纸 60% · 墨 25% · 运行青 10% · 其他 5%。
- 状态色（只用于产品界面）：警告 `#D9921A`、故障 `#D33A2C`、已停止 `#8A949E`。品牌色避开红、橙，避免与告警语义冲突。

## 字体

- 英文：IBM Plex Sans；中文落到系统中文黑体（苹方、思源黑体 / Noto Sans SC、微软雅黑）
- 日文：IBM Plex Sans JP
- 代码与数据：IBM Plex Mono

控制台与官网都**自带字体文件**（`fonts/`，SIL Open Font License），不从外部加载：控制台的安全策略禁止外部资源，官网在国内访问外部字体服务也不稳定。

## 形状与组件

- 可点击元素一律胶囊形：按钮、开关、状态标签；卡片圆角 16px；层级靠描边，不靠阴影。
- 开关（`role="switch"`）：开启时轨道为运行青，轨道内显示三个小圆点。
- 主按钮：墨色底；“一键开启”类动作在按钮右端带一个运行青圆形开关头。
- 状态标签：圆点 + 文字。运行中＝运行青；部署中＝虚线圆圈；失败＝故障色；已停止＝灰。
