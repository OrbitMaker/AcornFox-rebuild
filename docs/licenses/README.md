# AcornFox dependency notices

AcornFox source is licensed under AGPL-3.0-only. The complete license text is
`AGPL-3.0-only.txt`. Bundled dependencies retain their own terms.

`licenses-manifest.json` contains the version, public source URL, complete
upstream license/notice material, and its SHA-256 for each recorded component.
`LicenseRef-<sha256>` preserves an exact upstream notice set without inferring a
single license expression for mixed material.

`THIRD_PARTY_NOTICES.md` indexes those materials. Both files are generated by
`scripts/gen-licenses.py` and cover what a release actually ships:

- Go modules compiled into the `acornfox` binary (union over all release
  platforms) and the Go standard library;
- Caddy, attached unmodified to each release (version from
  `scripts/install/install.sh`);
- the IBM Plex fonts bundled with the web console and the website.

Rerun the script whenever `go.mod`, the Caddy version or the bundled fonts
change. An inventory entry is not an assertion that every source file in that
module is present in the compiled output.
